Panduan hosting dashboard Tanggap Darurat

CKAN tidak menyimpan dashboard. Portal hanya meng-embed dashboard yang sudah diproduksi (Superset, GIS, ArcGIS, dll.) ke kamar jenis bencana.

Syarat embed

  1. URL dashboard memakai HTTPS.
  2. Server dashboard mengizinkan iframe dari origin portal (hindari X-Frame-Options: DENY; preferensi CSP frame-ancestors yang memuat domain portal).
  3. Untuk Apache Superset, tambahkan standalone=1 agar navigasi Superset disembunyikan.
  4. Ukuran iframe mengikuti tinggi viewport di bawah header portal.

Cara menambahkan ke kamar

Sysadmin membuka /tanggap-darurat/kelola, mengisi title, iframe_url (HTTPS), dan sumber pada kamar yang sesuai, lalu Simpan. Data kamar hanya ada di sdbi_settings (key tanggap_rooms).
