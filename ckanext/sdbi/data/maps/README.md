# Source administrative boundaries (SHP)

Local-only shapefiles for regenerating simplified GeoJSON used by `/sebaran-bpbd`.

- `batas-kota-kab/` → `public/data/boundaries/kabupaten.geojson`
- `batas-provinsi/` → (later) `public/data/boundaries/provinsi.geojson`

Heavy sidecars (`.shp`, `.shx`, `.dbf`, `.sbn`, `.sbx`, `.qmd`) are gitignored. Keep them on disk for regeneration; see `public/data/boundaries/README.md`.
