Batas wilayah untuk peta BPBD (`/sebaran-bpbd`).

- `provinsi.geojson`: layer Provinsi (disederhanakan).
- `kabupaten.geojson`: layer Kabupaten/Kota (disederhanakan; fields include Kode, NAMOBJ, WADMKK, WADMPR, KDPKAB, TIPADM).

These public GeoJSON files are what the map loads at runtime. Do not serve raw SHP to the browser.
